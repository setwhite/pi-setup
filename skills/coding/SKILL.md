# Coding

## Step 1 — 领任务

取一条未开始或打回的任务；没有 `docs/TODO.md` 就问用户要范围。

**完成标准**：任务与验收标准明确。

## Step 2 — 红/绿 TDD

测试落在模块公共入口上，不测内部实现。

**完成标准**：新行为先有失败测试，再改到通过。

## Step 3 — lint + test

改完运行项目的 lint + test；修不了就给出报错。通过后在 `docs/TODO.md` 勾选对应任务，附 commit 或 diff。

**完成标准**：全绿；勾选与证据已写入。

## 模块

新模块一次建齐 README.md、公共入口（index.ts / __init__.py）、类型与契约、测试。需要改结构时停下问用户。

## 代码风格

- 函数体 ≤ 50 行、嵌套 ≤ 3 层、单文件 ≤ 300 行
- 位置参数 ≤ 3 个，超出改对象/数据类传参
- 魔法数字用命名常量（0、1、-1 等公认语义除外）
- 函数签名、类属性、数据类字段完整类型标注

### 通用

- 修改/新增代码保持现有代码风格
- 文档只做索引与事实陈述，信息唯一，不用文字复述代码逻辑
