# Coding

通用约束（语言、工程原则、需要确认才能做的操作）见 agent 的 `AGENTS.md`，这里只写开发流程。前提：`docs/TODO.md` 存在；没有就先跑 plan。

## Step 1 — 领任务

- 按顺序取 `docs/TODO.md` 里第一条「未开始」或「打回」且前置任务已完成的任务
- 取到后把状态改为「进行中」（状态词表见 `../plan/SKILL.md`）

**完成标准**：任务、验收、接口都已明确；任一不明确就停下问用户，不猜。

## Step 2 — 红/绿 TDD

- 一次一条垂直切片：先写失败测试（红），再写刚好让它通过的实现（绿），循环
- 测试贴在公开接口上，不测私有函数
- 重构不混进循环，留到收工统一做

**完成标准**：任务涉及的新增/修改行为都有对应测试，且全部通过。

## Step 3 — 收工

- 跑 lint 与测试，全绿
- 接口有变化时更新对应模块 README
- 把任务状态改为「待审」

**完成标准**：检查全绿、TODO 状态更新，然后停下等 review。提交走 commit-style skill。

## 代码风格

- 函数签名、类属性、数据类字段完整类型标注
- 文档只做索引与事实陈述，信息唯一，不用文字复述代码逻辑
