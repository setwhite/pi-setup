# Debug（诊断循环）

轻的直接答，别进循环：一眼可见的笔误、类型报错、没装的依赖。有 `docs/GLOSSARY.md` 与相关 ADR 就先读，建立心智模型。

## 脱敏

本 skill 你会展示命令、输出、抓包——先脱敏：密钥、token、cookie 写成 `<REDACTED>`；凭据走环境变量，不进展示内容；带 auth header 的日志只引有信号的那几行。脱敏后不够判断就说出来，向用户要。

## Step 1 — 造回路

**价值全在这一步。** 有能在**这个** bug 上变红的 pass/fail 信号，后面都是机械活；没有，盯代码无用。

### 手段

大致按此序：

1. 失败的测试——能触达 bug 的那层 seam（unit / integration / e2e）
2. curl / HTTP 脚本打本地 dev server
3. CLI：喂一个 fixture，stdout 与已知正确快照 diff
4. 回放抓包：真实请求 / payload / 事件日志存盘，单独喂进代码路径
5. 一次性 harness：最小子集（一个服务、mock 依赖）单次调用走 bug 路径
6. 属性 / fuzz：随机输入跑 1000 次，找失败模式
7. bisect harness：两个已知状态间自动「起 X、检查、重复」，可交 `git bisect run`
8. 差分：同一输入跑新旧两版或两套配置，diff 输出
9. 人在回路（最后手段）：只能人点时用脚本驱动人，输出仍要回传

### 打磨

- 更快：缓存 setup、缩测试范围
- 信号更尖：断用户那个症状，不是「没崩」
- 更确定：钉时间、种 RNG、隔离文件系统、冻网络

30 秒还会闪的回路约等于没有，2 秒且确定的才叫 tight。

### 闪烁的 bug

目标不是干净复现，是把复现率抬到可调的档位：循环触发 100 次、并行、加压、卡时间窗。

### 真造不出来

停下来说清楚，列出你试过的，向用户要 (a) 能复现的环境 (b) 脱敏后的抓包、日志或堆栈 (c) 允许加临时埋点。

**Completion criterion**：能点出**一条命令**（脚本路径、测试调用、curl），已经跑过至少一次，并贴出调用与输出（脱敏后），且它：

- [ ] 能变红：走真实 bug 路径，断言**用户说的那个症状**，不是「跑起来没报错」
- [ ] 确定：每次跑结论一样（闪烁 bug 按「闪烁的 bug」的复现率算）
- [ ] 快：秒级
- [ ] 可无人跑

**没这条命令就不许进 Step 2**——发现自己开始读代码建理论，停：这正是本 skill 要拦的失败。

## Step 2 — 复现 + 最小化

跑到红，确认三件事：是用户描述的那个失败模式，不是附近另一个；多跑几次都复现；症状（错误信息、错输出、慢了多少秒）已留存，供 Step 6 验收。

最小化：一次砍一个（输入、调用方、配置、数据、步骤），每砍一刀重跑；标准是删掉任何一个元素都会变绿。

## Step 3 — 列假设

先写 3–5 条并排序，再动任何一条：只提一条会锚死在第一个顺眼的念头上。每条可证伪，写出预测——「如果 X 是原因，改 Y 让它消失 / 改 Z 让它更糟」；写不出预测的是感觉，丢掉或磨尖。

测之前把清单给用户看：他们常有领域知识能一秒重排（「我们刚发过 #3 的改动」）或已知排除过哪些。用户不在就按自己的排序继续，别卡住。

## Step 4 — 埋点

每个探针必须对应 Step 3 的某条预测，一次只改一个变量。优先级：调试器 / REPL（一个断点胜过十行 log）> 在能区分假设的边界打靶向 log；「全打 log 再 grep」不算。

每条调试 log 带唯一前缀如 `[DEBUG-a4f2]`——收工一条 grep 清干净；没前缀的 log 会活下来。

性能回归另走一条路：log 通常是错的。先立基线（计时 harness、profiler、查询计划），再 bisect。先量，后修。

## Step 5 — 修 + 回归测试

先写回归测试，但要有正确的 seam：测试走真实 bug 模式在调用点的样子。只有浅 seam（该由多调用方驱动却写成单调用方测试、单测复不出触发链）时不写，那只会给假信心。

没有正确 seam 本身就是结论：记下来，架构挡住了这个 bug 的锁定，别写个浅测试盖过去。

有 seam 就按序做：最小复现改成失败测试 → 看它红（若红是改代码或夹具逼出来的，先 diff 一份干净副本，证明改动真的落地）→ 修 → 看它绿 → 用原始未最小化的场景重跑 Step 1 回路。

## Step 6 — 收工

- [ ] 原始复现不再复现（重跑 Step 1 回路）
- [ ] 回归测试通过，或已记下缺 seam
- [ ] `[DEBUG-` 埋点全清（grep 一遍）
- [ ] 一次性原型删掉
- [ ] 命中的那条假设写进 commit / PR 信息，让下一个调试的人学到
