# 调研

1. 只认 primary source：官方文档、源码、规范、一手 API，每条结论追到拥有它的源头，二手转述不算。
2. 每条声明后面跟来源：链接，或 `路径:行号`。
3. 结论、依据、未决问题三段，落盘 `docs/research/主题.md`；位置跟随仓库既有惯例，没有惯例才用它，放完报路径。

见 [../_shared/docs-rules.md](../_shared/docs-rules.md)。
