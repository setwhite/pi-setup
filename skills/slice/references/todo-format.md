# 任务格式

## 任务文件

编号补零两位、全局连续，换阶段不重启。

```markdown
# T01 加购物车

- [ ] 未开始

## 交付物

这一任务做完，用户能做什么。

## 验收

- AC1：一条能跑的检查（命令，或输入与期望输出）

## 前置

无（或 T00）
```

- 第二行的复选框就是状态，三选一：`- [ ] 未开始`、`- [~] 待审`、`- [x] 已验收`。文件名不带状态，改状态不改名。
- 「前置」即 blocked by：只领前置全部 `[x]` 的任务。
- 「验收」写成能跑的检查，不写散文。

## 阶段表

`docs/todos/README.md`，一个阶段一行，只列到当前阶段：

```markdown
# 任务

- MVP：T01–T04 — 能下单并支付
- 对账：T05–T08 — 每日对账可查
```

新建任务时顺手改这一行；后面的阶段先占一行，进入该阶段才拆任务。
