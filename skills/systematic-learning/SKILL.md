# 体系化学习

把孤立概念挂到知识树上，不给扁平定义。卡片顶部标检索日期，关键信息标来源。

## 五段结构

1. **核心本质**：讲给外行听。它是什么（一句话）、解决什么痛点（没有它时世界什么样）、为什么现在才出现（技术前提与时代背景）。
2. **知识坐标系**：上位概念（所属理论框架）、下位概念（核心要素、细分流派）、易混淆的对比，句式 `概念 A vs 概念 B —— 一句话区分`。
3. **演进脉络**：关键节点时间线、代表人物与贡献、前沿趋势与当前争论。
4. **案例分析**：一个经典场景加一个反直觉案例。说清背景、应用方式、为何选它。
5. **边界与误区**：何时失效、有何副作用、初学者最容易犯的错。

## 搜索

三路互不依赖，同一轮一起发：概念本身（核心原理、通俗解释、tutorial）、知识定位（对比区别、发展史与提出者）、边界与案例（局限误区、实战案例）。

多源确认过的才可信。单一来源标 `[单一信源]`。来源矛盾就列出双方依据与出处。

## 输出

按五段顺序生成 Markdown 卡片。
