# 体系化学习

把孤立概念挂到知识树上，不给干巴巴的词典定义；卡片顶部标 `date` 检索日期，关键论断附一手来源。

- Parallel Search：同一轮并行查三路——核心原理与一手源、上下位框架与演进史、实战案例与失效边界。
- Epistemic Hygiene：多源交叉验证为准；单一来源标 `[单一信源]`；信源矛盾并列双方依据。

## 五段卡片骨架

1. Feynman Essence：大白话一句话讲给外行听；解决什么痛点（没它时什么样）；出现的技术前提。
2. Knowledge Graph：上位框架、下位要素与流派、易混对比（`概念 A vs 概念 B — 一句话区分`）。
3. Evolution：关键时间线、代表人物与贡献、前沿趋势与当前争论。
4. Cases：1 个经典场景加 1 个反直觉案例，写清背景、用法与选型理由。
5. Boundaries & Pitfalls：何时失效、有何副作用、初学者高频陷阱。
