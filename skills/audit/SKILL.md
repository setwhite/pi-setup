# 审计流程

## 前置条件

- 独立会话：必须在未参与编写的新会话中运行。
- 只读：不修改 `docs/TODO.md` 与 git 已跟踪文件。

## Step 1 — 准备材料

1. 读取 `docs/TODO.md` 确认验收标准与证据指针。
2. 检查 Git 状态，确认改动范围。

完成标准：明确改动范围与验收标准。

## Step 2 — 核查

1. AC 核对：逐条核对验收标准。证据仅认当前会话运行输出。
2. 跑 E2E test
3. 对照 `AGENTS.md`，确认符合其中的规范

完成标准：每条 AC 有「达成 / 未达成 + 证据」；每个问题可定位到文件与行号。

## Step 3 — 输出

- Finding 格式：`文件:行号 — 观察 — 依据（AGENTS 条款或 AC 编号）`。
- 只给意见，不给实现方案，是否返工由用户决定

完成标准：意见精确定位到文件，未修改任何文件。
