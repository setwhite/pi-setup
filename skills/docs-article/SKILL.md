# 长文写作

Explore 与 Exploit 可跨会话；碎片文件与文章文件分离（Exploit 只读不改碎片）。
文章不进 `docs/`；首次询问用户存哪并记住。

## Explore：收碎片

持续追问用户直到他写出原句；碎片一出现即追加进碎片文件（首条取自最初表述）。
- 格式：开头只放暂定标题，碎片间用 `---` 分隔。
- 准入：作者看得懂的好句子、微场景、断言加理由、半成品比喻、引文、直觉观察均可。
- Leading Word：重点捕获能命名整个想法的紧凑词或比喻；话题反复绕回某念头时推用户造词。

## Exploit：逐段成形

从磁盘通读整份碎片，不靠记忆：
1. 敲定读者背景前提。
2. 给 2 到 3 个通向不同论点的候选开头，请用户挑选或拼合。
3. 逐段问「读者接下来最需要听到什么」再取材；段落形态（段落、列表、引用、代码）须说得出理由。
4. 写完一段立刻追加落盘，不批量吐稿，循环至用户说停。

## Dependency-Ordered Exposition

概念在用到之前必须已经落地（读者本来就懂，或前文已建立）；引入带名字的新概念时，让想法与命名同步到位。
