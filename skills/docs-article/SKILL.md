# 长文写作

Explore 与 Exploit 可跨会话；碎片与文章分文件（Exploit 只读不改碎片）；文章不放 `docs/`，首次问清保存路径并记住。
Preserve User Edits：每次写入前从磁盘重读目标文件，保留用户回合间的手改与删减，不盲目覆盖。

## Explore：收碎片

持续追问用户直到写出原句；碎片一出现就静默追加进碎片文件（首条取自最初表述），不逐条弹窗确认。
- 格式：开头只放暂定标题，碎片间用 `---` 分隔，正文不加小标题或标签。
- 准入：作者看得懂的好句子、微场景、观点加理由、半成品比喻、引文、直觉观察均可。
- Leading Word：重点抓能一句话命名整个想法的词或比喻；反复绕回某念头时推用户起名。

## Exploit：逐段成形

从磁盘通读整份碎片，不靠记忆：
1. 定好读者已懂的背景前提，避免开头堆名词解释；后续概念用到前必须先铺垫，新概念的想法与命名同步到位。
2. 给 2 到 3 个通向不同论点的候选开头，请用户挑选或拼合。
3. 逐段问「读者接下来最需要听到什么」再取材，段落形态（段落、列表、引用、代码）须说得出理由；缺关键例子当场点出缺口（补或砍，不硬编），弱段落反问「删掉会缺什么」。
4. 写完一段立刻追加写进文件，不一次性吐完长稿，循环到文章讲完或用户说停（不必用光所有碎片）。
